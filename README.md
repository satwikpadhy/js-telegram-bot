# JS Telegram Bot

A Telegram bot written in JavaScript that provides note-taking and management functionality for Telegram groups and private chats. This bot offers improved stability and a range of features to enhance your Telegram experience.

## Features

- Save and retrieve notes (text, images, videos, documents, audio, and voice messages)
- List all saved notes
- Delete notes
- Pin and unpin messages
- Encrypted storage of text notes for enhanced security

## Technologies Used

- Node.js
- PostgreSQL for data storage
- node-telegram-bot-api for Telegram Bot functionality
- crypto-js for encryption

## Setup and Running

1. Clone the repository
2. Install dependencies with `npm install`
3. Set up environment variables (see .env.example)
4. Run the bot with `npm run start`

For more detailed information on available commands, use the `/help` command when interacting with the bot.
